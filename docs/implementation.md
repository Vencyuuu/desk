# 桌面模式实现

## 交互入口

主程序没有管理窗口，也不在启动时弹出设置。桌面空白菜单创建空卡片；多选菜单把完整文件集合提交给常驻实例。高级操作与配置集中在托盘，Dock 只负责启动与添加应用。新建、改名和出错时可以出现短暂对话框。

旧 `MainWindow` 已移除。WPF `Window` 只作为生成 HWND 和控件树的技术载体；其原生样式变为 `WS_CHILD`，父级为 Explorer 的 `SHELLDLL_DefView`。

## 模块

| 模块 | 责任 |

| `FenceWindow` | 直接操作卡片、折叠、缩放、物理位置保存 |
| `DockWindow` | 快捷应用引用、真实图标、悬停动画和工作区底部定位 |

## 桌面嵌入

枚举顶层窗口，找到其下的 `SHELLDLL_DefView`，将卡片和 Dock 转为其子窗口并置于图标列表上方。没有替换 Explorer，也没有写入桌面背景或图标布局。没有找到桌面时暂时隐藏，定时重试，不回退为普通应用主窗口。

窗口重建检查每两秒执行一次。Explorer 销毁子窗口时，已关闭的卡片和 Dock 会重新创建。实际窗口销毁 / 恢复过程仍需跨 Windows 版本进行人工检查。

子窗口不调用 `Window.DragMove`，而是使用鼠标捕获、屏幕坐标与 `ScreenToClient` 移动。保存的坐标明确标记为物理像素，宽高保留 WPF 逻辑单位；旧布局在实际移动或保存时迁移。底部 Dock 按主屏工作区定位，不修改 Windows 任务栏。

## Shell 多选

当前用户注册表键：

```text
HKCU\Software\Classes\DesktopBackground\Shell\DeskNest.Create
HKCU\Software\Classes\AllFilesystemObjects\shell\DeskNest.Create
HKCU\Software\Classes\CLSID\{683ABCCE-019F-436B-A287-CAE2A3BFE665}\InprocServer32
```

桌面空白入口运行 `--new-card`。多选入口使用 `ExplorerCommandHandler` 和 `MultiSelectModel=Player`。原生 DLL 的 `Invoke(IShellItemArray*)` 枚举完整选择集合，写入一份 UTF-8 JSON 清单，然后启动 DeskNest。不能用 `%1` 静态命令替代，否则可能对每个文件分别启动，无法保证同卡收纳。

DLL 只做清单交接，不移动文件。COM 边界捕获 C++ 异常，不让异常进入 Explorer。主程序校验请求目录、清单大小、操作类型和文件数量，再通过当前用户专用管道交接给已有实例。原生扩展依据微软的 [IExplorerCommand::Invoke 文档](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-iexplorercommand-invoke) 实现。

扩展使用静态 C++ 运行库，不要求额外安装 VC 运行库。构建生成带内容版本的 DLL 名称，避免覆盖 Explorer 已加载的文件；`shell-extension.txt` 指向当前版本。

## 玻璃材质

WPF 分层子窗口和桌面宿主的组合不适合直接假定系统 DWM 背景材质可用。本实现读取本地壁纸，模糊一次并共享缓存；拖动时仅改变区域采样，再叠加浅 / 深色透明着色和高光。这是一种 Liquid Glass 的视觉近似，不等同于实时模糊其他窗口，也不声称拥有苹果的折射渲染。

微软提供的 [DWM 系统背景枚举](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type) 对 Acrylic 的版本和窗口行为有明确约束；当前实现没有把简单透明色宣称为原生 Acrylic。

## 文件语义

标题点击进入行内编辑，拖动超过系统阈值后才移动卡片，避免点击与拖动互相误触。名称保存失败会回滚；显示名称变化不改变分区 ID 或文件目录。搜索框在已有文件缓存中过滤，不在每次输入时重新枚举目录或提取图标，目录监听更新后继续应用当前查询。原底部信息栏已移除。

卡片托管会移动真实文件，Dock 固定只保留引用。重名自动编号，不覆盖。移除卡片只移除布局记录，其目录继续保留。原生文件菜单的删除作用于真实文件，按 Windows 的行为执行。

数据目录及其祖先不能被拖入自身。文件夹跨卷移动仍明确拒绝；后续应使用 `IFileOperation` 补充进度和取消，而非自行执行未经完整验证的复制后递归删除。

## 当前验证证据

设置页是按需打开的单实例窗口；常驻启动仍不显示管理窗口。新增 Dock 高度、背景不透明度字段使用兼容默认值，旧布局无需重建。外观设置先原子保存、再通知桌面控件，保存失败回滚内存。滑块变化防抖合并，关闭页面时同步保存待处理值。

自启动以 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 DeskNest 值为事实来源，不另外存储重复布尔值。只有用户切换开关时写入或移除自己的值，命令行正确引用含空格的程序与数据目录。当前用户登录后的实际重启过程尚未通过注销 / 重启验证；注册服务已用隔离测试键验证启用、关闭、路径引用和不影响其他值。

新增设置验证 14 项通过，包含页面单实例、保存 / 重开、Dock 高度与底部定位、只调整背景透明度、主题和玻璃开关、自启动开关同步 / 失败回滚、边界值及文件被占用后的保存重试。基础检查增至 33 项；设置页已生成浅深色预览并查看。

截图回归已复现并修复：旧输入框高 28，但文字视口仅 8–10，模板把 Padding 又作为宿主 Margin 扣了一次。修复后控件最小高 32、文字视口与文字范围相等，纵向滚动量为 0。Dock 改为相等的上下边距并移除添加按钮；文件列表不再叠放占位字形和真实图标。

Dock 使用本窗口的鼠标捕获处理拖出，不向 Explorer 发送文件移动或复制拖放。鼠标释放后按屏幕位置决定排序或移除引用，Esc / 捕获丢失取消。托盘和拖出复用同一引用移除入口并保存布局，源文件不动。名称提示显式打开，避免嵌入桌面的非活动窗口不触发默认提示。

新增回归检查覆盖完整输入行、图标上下留白、无加号、单层真实图标、悬停显示 / 离开关闭名称、文件夹固定、取消拖出、Dock 内排序、拖出移除、持久化及源文件内容保留。实际操作系统鼠标的跨显示器拖动仍需人工兼容性检查。

- 发布构建通过，C# 和原生 C++ 均完成编译；C++ 启用 `/W4 /WX`。
- 28 项文件 / 通信 / 状态与搜索检查通过，包含重名、恢复、真实图标、同用户命名管道、Dock 持久化、真实菜单入口及中文 / 全半角 / 多关键词模糊匹配。
- 9 项卡片控件检查通过：点击标题编辑、Enter 保存且目录不变、Esc 取消、空名称保护、失焦保存、即时搜索、无结果状态、Esc 清空、底栏移除且文件不变。

### 数据目录迁移与重新关联

拖动稳定性修复：卡片几何保存使用 `Persist(notify: false)`，只保存布局，不广播外观变更。普通原生定位在边界未变化时直接返回，使用 `SWP_NOACTIVATE | SWP_NOZORDER`，不再反复发送 `SWP_FRAMECHANGED`；只有初次修改父级和样式时刷新框架。新增真实 HWND 消息回归 `--drag-stability`：连续移动一张折叠卡片并保存，修复前观察到 24 次全局通知和 72 次无关卡片 / Dock 定位，修复后均为 0，最终坐标持久化正确。桌面父级、折叠、多选收纳和 20 项设置检查继续通过；录屏场景在不同显卡驱动和系统版本下的视觉兼容性仍需实际使用观察。

卡片增加可空 `BackgroundColor` / `TitleColor`，严格验证 RGB 颜色格式；托盘每卡片提供选色与单独恢复默认。`SetPartitionColors` 保存失败回滚内存，保存成功通知视图刷新。GlassSurface 支持可空材质着色，保留原透明度与壁纸采样；标题颜色优先级为卡片覆盖、全局标题色、主题色。字体条目提供已安装字体对象供 ComboBoxItem 预览，选中区域同步使用其字体。总字体通过一次合并更新同步三个子字体，重载时从三个区域是否一致推导显示，无重复持久化状态。设置滚动内容右侧保留 14 逻辑像素间距。字体与卡片样式专项现有 18 项通过，覆盖总字体联动、实际下拉项字体、独立颜色隔离、持久化和恢复默认。

字体配置集中在 `TypographyPreferences`：卡片、Dock、设置页各自保存字体名，另有全局卡片标题字号（10–32）和可空 RGB 颜色（空为跟随主题）。`FontCatalog` 仅从 WPF 系统已安装字体枚举中解析名称，避免将配置作为任意外部字体 URI 加载。中文字体名优先展示中文名称，缺失字体保留选择并回退默认；设置与数据迁移仍复用既有保存和回滚事务。卡片根字体向文件名与搜索控件继承，图标字体保持显式定义；Dock 独立 Tooltip、拖动 Popup 显式应用其字体。标题行和编辑框按字体行距增长，折叠高度同步。派生 Window 显式应用基础窗口样式，使主题前景色正确向普通文本继承，同时主按钮白字不受覆盖。

新增字体专项检查 13 项通过：字体列表、各区域独立应用、Dock 名称提示、友好名称、32 号标题编辑、颜色与主题、持久化、普通文字主题色、恢复主题颜色、缺失字体回退、非法配置保护和重开。基础检查 48 项通过；原有设置、迁移及输入 / Dock 视觉回归继续通过。已查看字体设置页截图。颜色选择器为系统原生对话框；所有已安装字体在不同 DPI 下的逐一人工检查尚未覆盖。

Dock 新增 `DockBottomOffset`，默认 12，允许 0–300 逻辑像素，与自身高度独立保存；旧配置缺失字段时自动使用默认值。定位换算 DPI 后从工作区底部扣除间距，并限制到可用高度，设置变化立即更新位置。取消全局 TextBlock 的主题前景色 setter，让按钮内部文字继承按钮颜色，解决 PrimaryButton 已设白色但生成的文字仍被全局样式改黑的问题；独立拖动 Popup 显式设置主题文字色。设置回归现有 20 项通过，基础检查 46 项通过，包含浅深色实际文字颜色、间距与高度独立保存、DPI 定位、零间距和上限、重开保留配置以及旧布局兼容。

入口目录与活动数据目录分离。默认入口仍是 `%LOCALAPPDATA%\DeskNest`，`--data-dir` 指定的是独立入口。入口中的 `location.json` 原子记录活动目录；互斥体、命名管道、自启动命令以及 Shell 请求位置保持稳定。不能删除仍在使用的入口定位文件。活动目录不可用时启动提示选择完整数据重新关联。

`DataDirectoryLease` 在读取生产数据前持有独占文件锁，防止多个入口同时使用同一份数据。迁移开始前保存布局，暂停应用文件操作与桌面修复；收到的 Shell 命令排队，成功后更新内部路径再执行。复制服务解析实际路径，拒绝自身、上下级和非空目标，不跟随重解析点。文件复制到目标父目录中的唯一暂存目录，逐项 SHA-256 校验；持有源文件只读锁并在复制后再次核对目录快照，阻止正在写入或增删文件造成的不一致。复制可取消，失败只清理本次暂存目录，源数据始终保留。

完整副本发布后，验证布局与所有卡片目录，重定位内部 Dock 路径。托管 `.lnk` 通过独立 STA 上的 `IShellLinkW` / `IPersistFile` 读取，修正存在于新目录的内部目标、工作目录及图标路径，不执行快捷方式。应用重建桌面窗口和文件监听后，最后提交入口定位文件；提交失败恢复原窗口、数据对象和活动目录锁。原目录留作备份，完整但未成功激活的副本也不会自动删除。关联已有目录不合并文件，采用该目录的布局和设置。

基础检查 44 项通过，新增目录集成检查 11 项通过，覆盖内容完整、空子目录、Dock 与快捷方式重定位、文件监听、自启动更新失败、定位文件提交失败回滚及手动搬移副本重新关联。真实应用多进程测试确认：从稳定入口启动后使用迁移数据，第二进程 Shell 请求写入新目录，退出重启后卡片继续保留。原有设置检查 14 项继续通过。所有验证使用隔离测试目录，不迁移真实用户数据；实际跨磁盘、大文件、断电及系统重启尚未人工验证。

以上不会代替对 Win+D、Explorer 重启、多显示器壁纸、真实鼠标拖放和每个第三方菜单命令的完整人工兼容性验证；这些仍明确保留为待验证范围。
